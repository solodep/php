# OOP Clothing Project (Вариант 8: Одежда)
Автор: Солод Алексей Александрович БПИ-248

## Описание
Проект моделирует систему учета одежды. Реализованы базовые классы товаров, интерфейсы для ухода за одеждой (стирка, глажка) и служебные механизмы.

## Требования
Проект выполняет следующие требования:
- [x] Минимум 5 классов.
- [x] Использование абстрактных классов и интерфейсов.
- [x] Использование трейтов (Logger, Validator).
- [x] Магические методы (`__construct`, `__destruct`, `__toString`, `__clone`, `__sleep`, `__wakeup`, `__debugInfo`).
- [x] Анонимный класс (в index.php).
- [x] Ключевое слово `final`.
- [x] Обработка исключений.

## Запуск
1. Убедитесь, что у вас установлен PHP 7.4 или выше.
2. Скачайте репозиторий.
3. Откройте терминал в папке проекта.
4. Запустите встроенный сервер:
   ```bash
   php -S localhost:8000
